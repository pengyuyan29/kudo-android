# 酷DO 0.2.2

## 新增

- 话题在前台自动加载新回复，并保留阅读位置。
- 回复按钮显示正在回复的用户头像。
- 楼中楼回复支持图片摘要，点击可进入画廊。
- 图片保存菜单显示原图大小和批量保存预估容量。
- 首页刷新后提示实际新增条数，无新内容时不提示。
- 支持 Obsidian Callout 提示块、正文表格和装饰引用样式。
- 已启用目录且包含章节标题的话题支持目录导航和章节跳转。
- 楼层选择改为可展开的黄色液态滑块，支持拖动和手动输入。
- 置顶帖默认精简单行显示，可在显示设置中关闭。
- 用户签名默认开启，保留已有的开关设置。
- 应用内提示统一为黄色背景、黑色文字的 Toast。

## 修复

- 完善列表封面的加载和失败重试提示，统一全屏图片和相册的三色加载动画。
- 修复“我的”页面吸顶身份的渐显效果。
- 修复深色模式网页加载时标题栏和状态栏闪白。
- 修正短话题滚动到底后的楼层计数。
- 访客页面和个人中心的“界面与显示”入口统一改为“设置”。
