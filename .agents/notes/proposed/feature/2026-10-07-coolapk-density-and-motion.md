# Agent Note: 酷安字号、信息密度与过渡节奏对照

Status: proposed

## Problem

底部导航已调整为扁平胶囊，但首页仍显得较大较松，顶部标签、列表摘要、详情标题和页面动画的比例尚未统一。用户要求在同机酷安上进一步对照字体大小、间距和动画。

## Proposal

用户已批准下面三个小单元。每单元至多涉及三个主要代码文件，独立构建检查并中文提交；验证和笔记随相应单元同步。字号与列表密度单元已实现，首页间距和动画单元仍待实施，因此本篇暂保留 proposed 状态。

1. 字号与列表密度：调整 KudoTheme.kt 与 Common.kt。作者名保留 15sp、时间 12sp；列表标题 17→16sp，摘要改为 14sp / 22sp；卡片内边距 16→12dp。详情正文使用独立于摘要的 16sp / 32sp，标题 23sp / 32sp 改为 22sp / 28sp；工具栏标题 21→18sp。
2. 首页与阅读间距：调整 FeedScreen.kt、TopicScreen.kt，必要时 RichContent.kt。顶部标签选中 21→19sp，未选中 17→16sp；搜索框 40→32dp；首页介绍区 122→88dp；列表两侧外边距 12→8dp、卡片间距 10→8dp。详情两侧内边距 18→16dp，作者头像 38→32dp；底部操作胶囊 57→48dp，图标 24→22dp。保留 48dp 操作触控区域，并检查大字号时是否需要自适应高度。
3. 动画节奏：调整 KudoApp.kt 与 Glass.kt。底部标签内容直接切换，选中玻璃胶囊采用更快收敛的弹簧，减少长尾；进入帖子采用约 280ms 淡入加轻微缩放，返回约 220ms，按压反馈约 100ms。不复用酷安的私有资源；时长是本项目建议值，录屏不能推定其所有内部参数。

## Existing note audit

检索了活跃笔记的玻璃、主题、导航与验证主题。[黄色玻璃导航与原生阅读界面](../../implemented/feature/2026-10-07-liquid-glass-ui.md) 部分重叠，保留其已实现的渲染和兼容边界；本篇只描述待批准的密度与动作调整。账号、协议和构建笔记无关。实施时把仍属于原有视觉决定的参数同步至原篇，本篇记录此轮对照依据和独立验收。

## Alternatives considered

- 把全局字号统一降低：改动最小、可快速增加信息密度，但作者和时间已与参考一致，详情正文行距还比参考窄；按内容角色分别调整。
- 每次切底部标签都加整页滑动：转场显眼且方向明确，但同机参考的内容直接切换，持续的整页位移也会干扰背景采样；只调整胶囊和进入 / 返回帖子的动作。
- 精确复制酷安所有布局与动画参数：观感可能最接近，但论坛话题、楼层和社区权限流程不同，XML 也不能证明运行时所有设置；使用可验证的比例并独立实现。

## Acceptance criteria

- 在相同真机与字号设置下生成调整前后截图，列表摘要基线间距为约 22dp，长文约 32dp；作者和时间保持清晰。
- 130% 字号、深色、中文长标题与多标签仍可读，顶部操作和底栏触控区域不被压缩或遮挡。
- 底栏点击和拖动仍可切页，经过中央按钮不触发发布；胶囊动画收敛自然。
- 进入 / 返回帖子动作可见且无白屏、内容重复绘制或明显背景采样闪动；系统关闭动画时操作仍可用。
- 构建、Lint、已有真机界面测试和 npm run verify-notes 通过；新增测试只覆盖发生改变的交互或实测缺陷，不对每个样式常量镜像断言。

## Risks

缩小固定高度可能在大字号下裁切文字，需要用真机复核并允许高度增长。详情正文增加行距会使长帖变长，这是阅读密度与可读性的主动取舍。玻璃动画和页面缩放组合可能增加绘制开销，需要用真机录屏检查，当前对照不构成正式帧率基准。
