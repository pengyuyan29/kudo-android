# Agent Note: 话题正文目录与标题跳转

Status: proposed

## Problem

话题正文中的 Markdown 标题目前只按普通标题样式渲染，没有可见目录。长文章需要反复滚动查找章节；页面已有回到顶部按钮，但没有与其并列的目录入口。

## Proposal

从主帖正文识别最上方的 `data-theme-toc="true"` 标记，并保留标题级别和纯文本标题；只有标记存在且正文包含规范 `h2` / `h3` 标题时才提取目录。回复、引用、签名和预览中的标题不参与；没有标记或只有其他级别标题的主帖不显示入口。标题在主帖正文中注册稳定锚点，目录点击请求标题滚入可视区域。目录按钮由回到顶部宿主在同一行渲染，复用液态玻璃材质；弹窗使用按钮位置作为展开原点并在选择章节后关闭。

目录不从引用、用户签名或回复预览生成；未加载的楼层不提前伪造目录项。没有标题时不显示按钮。

## Alternatives considered

- 只滚动到主帖顶部：改动较小，但长帖内的章节仍可能位于屏幕下方，不能满足章节跳转。
- 把所有回复标题合并到主题目录：可以收集更多标题，但与网页只对主题正文生成目录的行为不一致，会让普通讨论主题错误出现入口。
- 只支持 `h1`–`h4`：当前解析器已有这四级，但 Markdown/HTML 标题完整范围是六级，会让合法标题无法进入目录。

## Acceptance criteria

- 正文标题保留级别和可读文本，`h1`–`h6` 可提取并有 JVM 覆盖。
- 主帖同时满足 TOC 标记和 `h2` / `h3` 标题条件时，回到顶部同行最左侧显示 32dp 液态按钮；普通无目录主题、缺少标记或只有其他级别标题的主题不显示。
- 点击目录项能定位到对应标题，弹窗自动关闭；遮罩点击和返回键可关闭。
- 打开和关闭动画从目录按钮附近展开/收缩，且不影响原有回顶按钮和底部操作栏。

## Risks

帖子正文仍是单个 LazyColumn item，标题锚点只有在所属帖子被组合后才能请求滚动；跳转实现必须等待目标锚点注册，避免远距离点击停在帖子顶部。继续分页加载会改变目录数量，因此目录项使用帖子 ID 与标题路径组成稳定键。
