# Agent Note: 酷安字号、信息密度与过渡节奏对照

Status: implemented

## Problem

底部导航已调整为扁平胶囊，但首页仍显得较大较松，顶部标签、列表摘要、详情标题和页面动画的比例尚未统一。用户要求在同机酷安上进一步对照字体大小、间距和动画。

## Decision

列表、长文和导航分别控制字号与节奏。首页介绍区与搜索框使用最小高度而非固定高度；搜索框和缩小的头像外保留 48dp 点击区，帖子作者行整体可点击。

1. 字号与列表密度：KudoTheme.kt 与 Common.kt 使用 15sp 作者、12sp 时间、16sp 列表标题、14sp / 22sp 摘要和 12dp 卡片内边距。详情正文为 16sp / 32sp，标题为 22sp / 28sp，工具栏标题为 18sp。
2. 首页与阅读间距：FeedScreen.kt 的顶部标签选中 / 未选中为 19 / 16sp；搜索框最小 32dp，首页介绍区最小 88dp；列表外边距和卡片间距为 8dp。TopicScreen.kt 的详情内边距为 16dp，作者头像为 32dp；底部操作胶囊最小 48dp，图标为 22dp。字号放大时内容允许增高。
3. 动画节奏：KudoApp.kt 与 Glass.kt 保留底部标签内容直接切换，选中玻璃胶囊采用 spring(0.9, 650) 减少长尾；进入帖子采用 280ms 淡入加 0.97→1 轻微缩放，返回采用 220ms 淡出加 1→0.98 缩放。NavHost 的普通进入 / 退出使用 280 / 180ms 淡变、返回 220ms，与帖子过渡同步，避免底层默认时长拖慢整体结束。底栏按压用 100ms 缩放反馈，触控布局不随缩放变小。Compose 动画保留系统动画时长缩放支持。不复用酷安的私有资源；时长是本项目建议值，录屏不能推定其所有内部参数。

设备为 RMX2202 / Android 13，1080×2400，密度 480dpi（3px/dp），系统 font_scale 1.0。截图、布局和录屏均由真机获得，页面内容分别来自两个社区，不能比较整张卡片高度来推断字号。

## Existing note audit

检索了活跃笔记的玻璃、主题、导航与验证主题。[黄色玻璃导航与原生阅读界面](2026-10-07-liquid-glass-ui.md) 部分重叠，保留其渲染和兼容边界，并同步当前视觉参数；本篇记录密度与动作对照依据。账号、协议和构建笔记无关。

## Alternatives considered

- 把全局字号统一降低：改动最小、可快速增加信息密度，但作者和时间已与参考一致，详情正文行距还比参考窄；按内容角色分别调整。
- 每次切底部标签都加整页滑动：转场显眼且方向明确，但同机参考的内容直接切换，持续的整页位移也会干扰背景采样；只调整胶囊和进入 / 返回帖子的动作。
- 精确复制酷安所有布局与动画参数：观感可能最接近，但论坛话题、楼层和社区权限流程不同，XML 也不能证明运行时所有设置；使用可验证的比例并独立实现。

## Verification

三个单元的 Kotlin 编译通过。集中验收仍需完成：同机截图核对摘要 / 长文行距，深色 130% 字号与长标题检查，底栏点击及拖动不发布，帖子进入 / 返回录屏和关闭系统动画检查，以及 JVM、Lint、真机界面测试。新增测试只覆盖改变的交互或实测缺陷，不对样式常量镜像断言。

## Consequences

首页单位面积可以展示更多内容，正文更适合长文阅读；详情增加行距会使长帖变长。首页与操作栏保留最小高度，防止固定高度裁切放大的文字，仍需真机验证实际边界。玻璃动画和页面缩放组合可能增加绘制开销，录屏对照不构成正式帧率基准。
